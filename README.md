# 📘 پروژه PhoneBook - دفترچه تلفن

این پروژه یک دفترچه تلفن ساده و کاربردی است که با **Django** ساخته شده و امکانات زیر را دارد:

- افزودن، ویرایش و حذف مخاطبین
- نمایش مخاطبین در قالب کارت‌های مدرن
- طراحی واکنش‌گرا با **Bootstrap 5**
- پایگاه داده SQLite
